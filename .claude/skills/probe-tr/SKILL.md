# probe-tr

`kiwoom_docs`는 로컬에 없고, 문서와 실제 응답이 어긋난 사례가 계속 나왔다.
**먼저 찍고, 그 다음에 쓴다.**

## 절차

1. `references/probe-template.py`를 스크래치패드에 복사해 쓴다. 크리덴셜은
   `.env`/`.env.real`에서 읽되 **출력하지 않는다**.
2. path × body 후보를 돌려 `rc=0` + 행이 나오는 조합을 찾는다.
3. 배열 키·행 필드·전 행 공백 필드·페이지 크기·`cont-yn`을 덤프한다.
4. 파라미터를 **하나씩 값만 바꿔** 결과가 실제로 바뀌는지 확인한다.
5. `_AL`(통합) 수용 여부와 **어느 필드까지** 바뀌는지 확인한다.
6. 시간대를 타는 TR은 장전·동시호가·정규장 여러 시점을 찍는다.
7. 끝나면 프로브를 `plans/tools/`에 남긴다 (gitignore됨).

계약이 확정되면 CLAUDE.md의 "새 tool 추가 절차"로 넘어간다.

## Gotchas

- **rc=1은 경로가 틀린 것, rc=2는 파라미터가 틀린 것** — 경로 탐색의 신호다.
- **rc=2 메시지를 자르지 말 것** — 전문에 필수 파라미터 이름이 찍힌다.
- **필수인데 효과 없는 파라미터가 있다** — 값을 바꿔도 같으면 입력으로 노출하지 않는다.
- **응답 필드명을 믿지 말 것** — 의미가 응답에 없으면 아는 TR로 교차검증한다.
- **단위는 비율 필드로 역산해 확정한다.**
- **하한 파라미터의 무효 구간**과 "데이터 없음"은 다르다.
- **정렬돼 있다고 가정하지 말 것.**
- **KRX와 통합 스냅샷을 섞어 비교하지 말 것.**

각 항목의 실측 근거·사례는 `references/gotchas.md`.
