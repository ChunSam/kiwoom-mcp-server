# probe-tr

`kiwoom_docs`는 로컬에 없고 문서와 응답이 어긋난 사례가 계속 나왔다.
**먼저 찍고, 그 다음에 쓴다.**

## 절차

1. `references/probe-template.py`를 스크래치패드에 복사. 크리덴셜은 읽되 **출력 금지**.
2. path × body 후보로 `rc=0` + 행이 나오는 조합을 찾는다.
3. 배열 키·행 필드·전 행 공백·페이지 크기·`cont-yn`을 덤프한다.
4. 파라미터는 **하나씩 값만 바꿔** 효과를 본다. `_AL` 수용 여부와 시간대도 함께.
5. 프로브는 `plans/tools/`에 남긴다(gitignore). 확정되면 CLAUDE.md "새 tool 추가 절차"로.

## 판정 기준

**`references/gotchas.md`(15건)를 프로브 전에 읽는다.** 목록만 보고 넘기면 반드시 물린다 —
`rc=1`/`rc=2` 가르기, 0행의 원인, 효과 없는 필수 파라미터, 이름 불신과 역산 두 갈래
(방향은 행 통계 / 주체는 확정된 TR의 컬럼 대조), 단위, 잠정치와 확정치, 정렬·스냅샷 가정.
